# Original experiment source

These scripts are an immutable method/provenance archive, not the recommended command-line interface. Original file hashes are recorded in `../docs/source_file_manifest.json`. See `../docs/REPRODUCIBILITY.md` before running them.

Key source groups:

- 02–05, 07: data download/preparation and the exact AAC/DPC/physicochemical formulas.
- 09–10, 18: historical MMseqs2 clustering and partition preparation.
- 14, 26, 28: mRMR, seven algorithms, five-fold comparison and matched splits.
- 35, 37: final SVM migration and input audit.
- 27, 34, 36: five-fold reporting and SVM publication figures.
- 40–42: final visual revisions, including SVM draw order and the random-fold lower-triangle pairwise heatmap.
- 43: a separately saved exploratory dotplot, not the final Figure 6B.

LightGBM and TreeSHAP names may legitimately appear in historical source. They do not change the final model or the current results.
